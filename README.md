# 杀戮尖塔 存档助手 (Slay the Spire Save Assistant)

一个 Windows 上的《杀戮尖塔》**存档快照 / 一键回档**小工具。纯 PowerShell + WinForms 编写，
**不需要安装任何东西**（Windows 自带 PowerShell 即可），不修改游戏本体，只在存档目录里复制文件。

> 为什么需要它？游戏本身只在进入房间的瞬间存一次档，而且只保留**一层**备份文件。
> 一旦"选了下一关发现必死"，能退的最多只有一格。这个工具每 5 秒盯着存档目录，
> 只要游戏写一次档就另存一份带时间戳的快照，于是可以退 2 格、3 格、退到某个商店之前、某个篝火之前。

---

## 功能

| 功能 | 说明 |
|---|---|
| **自动快照** | 每 5 秒检查一次存档目录，只要文件变化就整份拷贝一份快照（自带去重，不会存重复内容） |
| **可视化列表** | 显示每份快照的存档时间、**当时所在**（战斗 / 商店 / 篝火 / 宝箱 / 精英 / Boss / 事件名 / 怪物名）、大小 |
| **一键还原** | 选中任意一份 → 还原（列表双击也行）。还原前会**自动把当前存档另存一份**，随时可以反悔 |
| **安全校验** | 游戏正在运行时拒绝还原（游戏只在启动时读档，必须先退出）；写入失败会明确提示原因 |
| **自动清理** | 默认只保留最近 300 份快照，旧的自动删除（每份只有几十 KB） |
| **零依赖** | Windows 自带 PowerShell + WinForms，不联网、不装运行库、不需要管理员权限 |

「当时所在」是**读游戏的日志推断**出来的：解析 `sendToDevs/logs/SlayTheSpire.log`，
以及游戏每次重启时归档的 `*.log.zip`，所以重启游戏也不会丢标注。

## 快速开始

1. 下载/克隆本仓库到任意目录；
2. **双击 `杀戮尖塔存档助手.bat`**；
3. 第一次运行会让你确认游戏目录（自动找不到时手动选一次，会记到 `settings.txt`）；
4. 之后正常玩游戏即可 —— 工具开着就会一直记录。

> 建议：玩游戏时**一直开着**这个窗口（最小化也行），这样每个房间的快照都不会漏。

### 还原存档

1. **完全退出游戏**（工具会检测，游戏在跑时会拦住你）；
2. 在列表里选中要回到的那一行 → 点「还原到这个存档」；
3. 启动游戏 → 主菜单点「继续 / Continue」。

还原前，当前存档会自动备份到 `快照目录\_before_restore_时间戳\`，所以随时可以再换回去。

## 环境要求

- Windows 10 / 11（Windows PowerShell 5.1，系统自带）
- 无需管理员权限，无需 .NET 安装，无需 Python
- 游戏：Steam 版《Slay the Spire》，以及各种**整合包 / 学习版**（只要目录里有 `saves` 文件夹即可）

---

## 游戏目录怎么找

按以下顺序自动查找，找不到就弹窗让你选一次（选择结果保存在 `settings.txt`）：

1. `settings.txt` 里的 `GameDir=`
2. 常见 Steam 路径：`C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire`、各盘符的 `Steam` / `SteamLibrary` ...
3. Steam 的 `libraryfolders.vdf` 里登记的其它库位置
4. 手动选择（任意整合包目录都行，例如 `D:\Games\SlayTheSpire-Mod`）

`settings.txt` 示例（放在脚本同目录，可手动编辑）：

```ini
# 杀戮尖塔存档助手 配置
GameDir=D:\Steam\steamapps\common\Slay the Spire
# 可选：自定义快照存放位置，默认在桌面 sts_save_history\
HistoryDir=D:\my_sts_backups
```

## 快照存在哪里

默认在 **桌面 `sts_save_history\`** 下，每份快照是一个以时间命名的文件夹：

```
sts_save_history\
  20261007_160728\          <- 快照文件夹名 = 记录时刻
    THE_SILENT.autosave     <- 当时 gamesaves 目录里的文件，原样拷贝
    THE_SILENT.autosave.backUp
  20261007_161831\
  _before_restore_20261007_203012\   <- 还原前自动留下的反向备份
```

每份大约几十 KB；默认保留最近 300 份。想清空直接删这些文件夹即可，工具不依赖它们。

## 常见问题

**Q：点还原提示「拒绝访问」？**
A：说明这个窗口权限不足。请关掉窗口，改为**双击 `杀戮尖塔存档助手.bat`** 启动
（由你自己双击启动的进程才有写入游戏目录的权限）。

**Q：还原时提示「游戏正在运行」？**
A：游戏只在启动时读档，所以必须先**完全退出游戏**（不是回主菜单，是退出进程）再还原，
还原后重新启动游戏点「继续」。任务栏里残留的进程也会被检测到。

**Q：启用了 Steam 云同步怎么办？**
A：还原后启动游戏时，Steam 可能拿云端的旧存档覆盖本地。建议还原前先退出 Steam，
或在 Steam 库里把该游戏的云同步关掉，再还原、启动。

**Q：会改坏我的游戏文件吗？**
A：不会。工具只对 `saves` 目录里的文件做复制（快照 = 拷出，还原 = 拷回），
不碰 `desktop-1.0.jar`、不碰游戏设置，也不写注册表。还原前还会自动留一份反向备份。

**Q：商店里买的东西没被记录？**
A：这是游戏自身的行为：商店内的购买不写档，只有离开房间才写。所以"重挑商品"不需要回档，
直接读档重进商店即可（不过那样只能逛当前这个商店；回退一格可以两个商店都逛）。

**Q：支持铁甲战士 / 故障机器人 / 观者 / 每日挑战吗？**
A：支持。工具不关心角色，整份 `saves` 目录一起拷贝还原。

**Q：多个角色存档会互相影响吗？**
A：不会，快照是整目录拷贝，还原也是整目录拷回。

**Q：能当"外挂"改数值吗（改金币、删诅咒、回血）？**
A：不能，本工具不做存档内容解析/修改，只做快照与还原。

## 命令行用法（控制台版）

不想开界面时，可以只用 `sts_save_watch.bat`（只有记录功能，无还原界面）：

```bat
sts_save_watch.bat
:: 或指定游戏目录与参数
powershell -ExecutionPolicy Bypass -File sts_save_watch.ps1 -GameDir "D:\Steam\steamapps\common\Slay the Spire" -IntervalSeconds 5 -KeepLast 300
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `杀戮尖塔存档助手.bat` | 启动图形界面（双击它） |
| `sts_save_gui.ps1` | 图形界面主程序（快照 + 浏览 + 还原） |
| `sts_save_watch.bat` / `sts_save_watch.ps1` | 控制台版，仅有自动记录功能 |
| `settings.txt` | 本机配置（游戏目录等），首次运行自动生成，**不应提交到仓库** |
| `sts_save_gui.log` | 运行日志，排错用 |
